## Reusing these files

When redistributing code or SVG artwork from this repository, preserve the MIT
copyright and permission notice with the copied materials. A notice in your
repository's license or notices file can accompany them. The license does not
require a visible credit banner in the profile design. Keep the full applicable
notice, rather than replacing it with only a link.

## Build infrastructure and references

The workflows invoke actions/checkout, actions/setup-node,
actions/upload-pages-artifact and actions/deploy-pages. These actions execute
from their upstream GitHub repositories; their source is not copied into the
application or Pages artifact. Linked documentation and existing ROGFOG projects
are references, not bundled components.

If you add an external component, record its source, version, covered files and
required notices here before distributing it.
